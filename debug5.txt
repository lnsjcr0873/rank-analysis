    augments
        .as_array() // ❌ 严重错误：直接尝试将 augments 转为数组
        .map(|arr| {
            arr.iter()
                .filter_map(|it| {
                    let id = it["id"].as_i64()?;
                    let name = it["name"].as_str()?.trim();

原因分析：

只有 ocr.rs 中的 build_lexicon 误以为它是裸数组，调用了 augments.as_array()。
由于类型不匹配，as_array() 必然返回 None，进而触发 unwrap_or_default() 返回了一个完全为空的词典。

修复方案：
code
Rust
let items = augments.get("data").and_then(Value::as_array).or_else(|| augments.as_array());

原因分析：
游戏客户端 /liveclientdata/eventdata 端点返回的是整场比赛自开局以来的全部历史事件数组（包含小龙、塔皮、击杀、助攻等）。

  const me = myPlayer(snapshot, myGameName)
  if (!me) return null
  const mySide = me.team
  const myTeamGold = teamGold(snapshot, mySide)
